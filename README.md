# Felipe Romao da Silva - Portfolio

Um portfólio digital desenvolvido com React, JavaScript e HTML.

## 🎯 Características Principais

### Seções
1. **Hero** - Hero com Apresentação pessoal
2. **About** - Seção editorial com tipografia e layout
3. **Skills** - Apresentação de tecnologias com categorias
4. **Projects** - Galeria de projetos 
5. **Contact** - Encerramento 
6. **Navbar** - Navegação
## 🛠️ Stack Técnico

- **React 18** - Framework UI
- **Vite** - Build tool otimizado
- **Framer Motion** - Animações e transições
- **Three.js** - (disponível para animações 3D avançadas)
- **CSS Puro** - Design tokens e styling
- **Google Fonts** - Tipografia premium (Sora, Inter, JetBrains Mono)
